My work

The software behind the tournaments

Stupa Events' Event Management System (EMS) is online software that table tennis federations subscribe to for running their tournaments. One platform serves many federations, each with its own events. I built two of its core modules, fixture creation and match scheduling, plus the streaming platform where fans watch. Today it is live in four regions.

What it does, step by step

Step 1 · Before the event · Module I built

Fixture creation

Organisers enter the players, and the system creates the fixtures: who plays whom in every round, from the first match to the final. It supports several tournament formats, so nobody has to draw it up by hand.

  • Works for different tournament formats
  • Moves winners forward round by round
Step 2 · On match day · Module I built

Match scheduling

It plans which match is played on which table and at what time. That way many matches can run across many tables without clashes, and organisers can keep the day on track.

  • Assigns matches to tables and time slots
  • Helps organisers manage changes during the day
Step 3 · At the table

Scoresheet printing

For each match, it produces the official scoresheet, ready to print and hand to the umpire, who records the score game by game.

  • One sheet per match, ready to print
  • Event, table and players already filled in
